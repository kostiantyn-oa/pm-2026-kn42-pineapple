## 2. Як рахувалася симуляція

| Поле | Значення |
| --- | --- |
| Інструмент | власний скрипт Python, `lr09_forecast/simulate.py` |
| Прогонів | 10000 |
| Що тягнеться випадково | velocity одного з моїх спринтів (у мене їх два, обидва 16) |
| Як рахується дата прогнозу | для сценарію «весь перший реліз» кінець спринта 1 плюс (P − 1) × 14 днів, для сценарію залишку кінець останнього спринта плюс P × 14 днів |

Одна симуляція це уявний проєкт: беру залишок points і, поки він більший за нуль, випадково тягну одну velocity з історії, віднімаю її і рахую спринт. Коли залишок дійшов до нуля, записую кількість спринтів. Роблю це 10000 разів, сортую результати і беру P50 (результат посередині) та P85 (результат, у який вклалось 85% проєктів). Генератор випадкових чисел фіксований (`SEED = 2026`), щоб прогін повторювався з тими самими числами. Сам код лежить у `lr09_forecast/simulate.py`, ось його основна частина:

```python
"""Прогноз методом Monte Carlo: скільки спринтів потрібно, щоб закрити залишок points.

Одна симуляція: беремо залишок і, поки він більший за нуль, випадково тягнемо
одне число зі списку velocity, віднімаємо його і рахуємо спринт. Коли залишок
дійшов до нуля або нижче, записуємо кількість спринтів. Повторюємо багато разів.
"""
import math
import random

SIMULATIONS = 10000
SEED = 2026          # фіксуємо, щоб прогін можна було повторити і отримати ті самі числа
MAX_SPRINTS = 200    # запобіжник на випадок, якщо у списку самі нулі


def simulate(remaining, velocities, simulations=SIMULATIONS, seed=SEED):
    rng = random.Random(seed)
    results = []
    for _ in range(simulations):
        left = remaining
        sprints = 0
        while left > 0 and sprints < MAX_SPRINTS:
            left -= rng.choice(velocities)   # випадковий спринт з нашої історії
            sprints += 1
        results.append(sprints)
    results.sort()
    return percentile(results, 0.50), percentile(results, 0.85)


def percentile(sorted_results, p):
    # число, нижче або на рівні якого лежить частка p результатів
    index = math.ceil(p * len(sorted_results)) - 1
    return sorted_results[index]
```
